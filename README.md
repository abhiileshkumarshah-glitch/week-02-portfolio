# Week 02 Portfolio Project

## Project Overview

This project is a personal portfolio website created for Week 02 lab. The website introduces me, shows my skills and interests, displays my projects, and includes a working counter page with React state. The goal of this project was to practice building a multi-page website using Next.js, React components, navigation, styling, and basic interactivity.

## Pages Included

* Home page
* About page

* Contact page

## Features

* Shared navigation menu across all pages
* Personal introduction and bio
* Projects page showing my practice projects
* Contact information page
* Interactive counter with Increment, Decrement, and Reset buttons
* Count display using the required `#count-display` ID
* Responsive and clean layout

## Technologies Used

* Next.js
* React
* TypeScript
* CSS
* GitHub
* Vercel

## Counter Functionality

The counter page includes three buttons:

* Increment button increases the count
* Decrement button decreases the count
* Reset button changes the count back to 0

The count value is displayed using:

```tsx
<h2 id="count-display">{count}</h2>
```
